# 评估闭环手册

没有评测数字的优化只是猜测。本手册给出最小可复现的评估闭环：
golden set 构建 → 四指标 A/B → 判定与回滚。

## Golden Set 构建

1. 收集 10-20 个真实任务样本。一个样本 = 一份真实输入 + 该输入下的期望产出；
   样本形态由 skill 领域决定（一份材料/一段需求/一个数据文件等）
2. 每个样本预埋期望锚点（命名随领域：问题/要点/结论锚点）：
   - 2-3 个高价值锚点(P0 级)
   - 若干中价值锚点(P1 级)
   - 若干规范/格式类锚点(P2 级)
3. 覆盖三类场景：典型、边界、至少一个大体量输入
   （大体量样本专门用于暴露 context rot）

## 四指标 A/B

对同一 golden set 分别运行优化前后两版 skill,统计:

| 指标 | 定义 | 方向 | 权重 |
|---|---|---|---|
| 核心目标召回/达成率 | 命中的预埋高价值要点数 / 预埋总数 | 越高越好 | 最高 |
| 无效输出率 | 不成立的输出条目 / 总条目 | 越低越好 | 高 |
| 低价值条目占比 | 低优先级条目 / 总条目 | 越低越好 | 中 |
| 输出长度 | 总字数或总条目数 | 信息密度代理 | 参考 |

指标名随 skill 领域换装（召回率/覆盖率/准确率、跑题率/臆造率/格式偏差率等），
四指标的框架和下方判定规则不随领域变。

判定规则(下文以"核心指标"指代召回/达成率):
- 核心指标升、无效输出率稳 → 优化成立
- 核心指标升、无效输出率显著恶化 → 条目改写过猛,放宽触发条件后重测
- 核心指标降 → 回滚并重新诊断,优先怀疑删掉了真增量知识
- 核心指标平、输出更短更密 → 成立(低价值条目被压掉)

## 逐项消融(可选,用于精细定位)

整体 A/B 定位不了收益来源时,做五次单因子实验:
1. 只删通用知识 → 知识提纯的独立贡献
2. 只加路由表 → 分层加载的独立贡献
3. 只改条目格式 → 可执行化改造的贡献
4. 只改两阶段流程 → 工作流的贡献
5. 全部组合 → 验证无负向叠加

## 注意事项

- 结论绑定模型:skill 换模型后必须重跑;条件允许时跨模型档位各跑一轮,避免过拟合单一档位
- golden set 有保质期,每季度补新样本
- 每次保留 A/B 双方的原始输出,供事后复查
- 汇报时给 delta 视角:多花/省下的 token 买到了什么——成本上升而核心指标不动的改动不采纳
- 触发质量单独测:should-trigger / should-not-trigger 两组提示词实测触发命中率,不计入四指标
- 可用 LLM-as-judge 按预埋锚点自动判分,但 PASS 必须附原文证据,并人工抽检校准
